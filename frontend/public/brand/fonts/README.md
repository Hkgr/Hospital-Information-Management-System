# خط الواجهة المرفق

ملف الهوية الأصلي لا يحتوي على خطوط مضمّنة ولا أسماء خطوط قابلة للاسترجاع؛ جميع النصوص حُوّلت إلى مسارات vector outlines. لذلك تبقى كتابة الاسم الرسمية مطابقة تمامًا داخل ملفات SVG ولا تعتمد على أي خط خارجي.

لجعل التطبيق قابلًا للتشغيل مباشرة، أُرفق بديل مفتوح الترخيص باسم CSS موحّد `MBZ Sans`:

- العربية: Noto Sans Arabic، وزنا 400 و700.
- اللاتينية: Noto Sans، وزنا 400 و700.
- الصيغة: WOFF2 محسّنة للويب.

هذه الخطوط بديل وظيفي للواجهة وليست ادعاءً بأنها الخطوط الأصلية المستخدمة في تصميم الهوية. عند استلام أسماء أو ملفات الخطوط الأصلية من المصمم، استبدل ملفات WOFF2 مع إبقاء أسماء الملفات، أو عدّل `css/brand-fonts.css`.

الترخيص: SIL Open Font License 1.1، راجع `OFL-1.1.txt`.
