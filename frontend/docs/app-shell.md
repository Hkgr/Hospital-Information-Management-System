# Application Shell

هذه المرحلة تنفّذ الهيكل المحيط بالصفحات فقط، دون محتوى Dashboard أو إحصاءات أو بيانات طبية.
المسار `/` يستخدم مجموعة `(hospital)`، بينما `/login` يبقى خارجها. صفحة Dashboard تُرجع
`null` عمدًا، لتظل مساحة المحتوى جاهزة للمرحلة التالية دون placeholder في المنتج.

## التصميم

- Sidebar يمين الشاشة يبدأ من الأعلى، بعرض 268px وارتفاع `100dvh` على Desktop.
- الهيدر وBrand Corner بارتفاع 80px ومتصلان مباشرة. السايدبار بتدرج رأسي من ألوان
  `--mbz-action` و`--mbz-blue` و`--mbz-teal` فقط. يمزج الوسط 55% من الأزرق والنهاية
  30% من الفيروزي مع لون action العميق، لإبقاء النص الأبيض واضحًا والتدرج هادئًا.
- الهيدر والفوتر أبيضان بلا حدود أو فجوات أو ظلال فاصلة. الخلفية `--mbz-surface` داخل
  Main تنحني عند اتصالها بالسايدبار في الأعلى والأسفل: 20px على Desktop و16px على Mobile.
  الانحناء في الحافة الداخلية فقط؛ لا مستطيلات منفصلة مستديرة حول أجزاء الإطار.
- مسافة الـworkspace تُحسب من عرض السايدبار باستخدام `margin-inline-start`. الهيدر
  وMain والفوتر كلّها داخله، لذا لا تمتد خلف السايدبار.
- Tablet ‏768–1279px يبدأ بشريط أيقونات 84px، ويمكن توسيعه إلى 268px. اختيار الطي/التوسيع
  يبقى في ذاكرة المكون فقط ولا يستخدم تخزين المصادقة.
- Mobile أقل من 768px يستخدم هيدر كامل العرض بارتفاع 72px، ودرجًا من اليمين بعرض يصل
  إلى 300px. يعتمد `dialog.showModal()` مع تعطيل تمرير الخلفية، وحصر Tab داخل الدرج،
  وEscape وإغلاق الخلفية وإعادة التركيز إلى زر الفتح. الانتقال إلى Desktop يغلق الدرج.
- الفوتر أبيض بسيط بارتفاع أدنى 48px، أسفل المحتوى فقط. الصفحات القصيرة تبقيه أسفل الشاشة؛
  الصفحات الطويلة تدفعه طبيعيًا إلى الأسفل. Main بلا ارتفاع ثابت، وحاوية children تعزل
  التمرير الأفقي عند وجود محتوى عريض مستقبلًا.
- ألوان MBZ الحالية وخط Cairo المحلي مع CSS Module. أضيفت نسختا الشعار العربي والدرع
  **البيضاوان الأصليتان** من Brand Kit دون تعديل، للسايدبار المفتوح والمطوي والدرج.
  لا خلفية منفصلة خلف الشعار ولا تغيير نسب أو ألوان أو ظلال؛ ملفات شعارات Login الملونة محفوظة.
- راجعت أصول الهوية: الدرع والنخلة والصليب الطبي والرعاية الإنسانية رموز للهوية وليست
  مجموعة تنقل كاملة. لذلك بقيت الأيقونات الخطية المستديرة من `react-icons/lu` الموجودة.
  حجمها 19px وسماكتها 1.7، داخل حاويات 32px بانحناء 9px وخلفية بيضاء 8%.
  النص أبيض 94% والأيقونات 88%؛ العنصر الحالي أبيض كامل بخلفية 18% ومؤشر يمين 3px.
  Hover يستخدم 12%، أو 22% للعنصر الحالي، وانتقالًا لونيًا 180ms دون تحريك العناصر.
  `prefers-reduced-motion` يلغي هذه الانتقالات وحركة الدرج. مؤشرات التركيز بيضاء على السايدبار.

## الخط المحلي

الخط الأساسي للواجهة كلها، بما فيها Login والـAppShell، هو Cairo. ملفه الأصلي وترخيصه
محفوظان في `public/fonts/cairo`، ويحمّله `globals.css` من ملفات المشروع عبر `@font-face`
مع الأوزان 200–1000 و`font-display: swap`. لا تنزيل خطوط أثناء البناء أو الاستخدام،
ولا اتصال بـGoogle Fonts أو CDN. تبقى ملفات الهوية السابقة دون تغيير، لكن stylesheet
الخط القديم لم يعد مستوردًا. نص الشعار نفسه SVG ولا يعتمد على Cairo.

## التاريخ والساعة

يعرض `HeaderDateTime` التاريخ والوقت الفعليين باستخدام `Intl.DateTimeFormat`، باللغة
`ar-SY` والمنطقة `Asia/Damascus` بصرف النظر عن منطقة جهاز المستخدم. التاريخ يتضمن
اليوم والشهر والسنة، والوقت ساعة ودقيقة ونظام 12 ساعة مع الفترة العربية. يتحدث كل
30 ثانية وعند تغير ظهور التبويب، وتزال المؤقتات والمستمعات عند إزالة المكون.

يستخدم `useSyncExternalStore` مع قيمة خادم `null` مشتركة مع أول hydration، ثم يقرأ
ساعة العميل. لا `suppressHydrationWarning` ولا مكتبة تاريخ ولا نص وقت ثابت. لا توجد
منطقة live تُعلن الساعة لقارئ الشاشة كل نصف دقيقة.

ترتيب الهيدر RTL: عنوان الصفحة، مساحة مرنة، التاريخ/الوقت، التنبيهات، الحساب الحقيقي.
التاريخ 12px والوقت 15px (14px على الهاتف)، بلا بطاقة أو حدود. على الهاتف يختصر
التاريخ إلى اليوم والشهر، وأقل من 360px تظهر الساعة فقط. يختفي اسم الحساب في الهيدر
أقل من 1024px لتبقى مساحة كافية عند توسيع قائمة Tablet؛ يظل الاسم كاملًا في قائمة الحساب
واسم زر الوصول. لا subtitle أو دور مختلق، ويظل اسم المستخدم الحقيقي في تفاصيل الحساب.

## التنقل والحساب

لوحة التحكم هي رابط التنقل الوحيد المنفّذ حاليًا. الاستقبال والعيادات والإسعاف والتنويم
والعمليات والمخبر والأشعة والصيدلية والفوترة والتقارير، ثم المستخدمون والإعدادات في قسم
إداري منفصل، عناصر معطلة ذات أسماء وصول توضّح أنها غير متاحة بعد. لا روابط `#` شكلية
للأقسام ولا صفحات أو صلاحيات مختلقة. زر التنبيهات معطل دون عدّاد أو تنبيهات فعلية.

اسم المستخدم وinitials واسم الحساب تؤخذ من استجابة `currentUser` الموجودة. قائمة الحساب
تستدعي `logout` نفسه، وتعرض تنبيه `must_change_password` الموجود سابقًا عند الحاجة.
عند فشل الخروج تبقى القائمة مفتوحة وتعرض رسالة الخطأ مع إمكانية إعادة المحاولة.

انتقل فحص المصادقة السابق من `IdentityPage` إلى `AuthenticatedLayout` دون تغيير طلبات
`/hospital-api/login` أو Bearer أو sessionStorage أو `currentUser` أو `logout`.
لا يُعرض الـShell قبل نجاح جلب المستخدم. بقيت معالجة انعدام التوكن و401 والحساب المعطل
وفشل الشبكة وفق الآلية القائمة. Laravel ما زال مسؤولًا عن المصادقة والصلاحيات.

## التحقق الفعلي

فُحصت نسخة البناء النهائية محليًا على `http://127.0.0.1:3101`، بالإضافة إلى معاينة
التطوير على `http://127.0.0.1:3100`. استُخدم Edge عبر Playwright لأن أداة المتصفح المدمج
تعذرت بسبب خطأ إعداد بيئتها.

| الأمر / الفحص | النتيجة |
| --- | --- |
| `node node_modules/typescript/bin/tsc --noEmit` | ناجح |
| `npm run lint` | ناجح دون أخطاء أو تحذيرات |
| `npm run build` | ناجح، والمسارات `/` و`/login` محفوظة |
| `node --test tests/auth-ui.test.mjs tests/app-shell.test.mjs` | بعد تحديث Cairo: 15 ناجحًا، 0 فشل، اختبار MySQL اختياري لم يُعد تشغيله |
| `php artisan test-db:check --connect --env=testing` | ناجح، mysql / hospital_testing / 127.0.0.1:13306 |
| `git diff --check` | ناجح |

متغيرات فحص المتصفح: `TEST_BASE_URL=http://127.0.0.1:3101` و`PLAYWRIGHT_CHANNEL=msedge`.
عند تنفيذ الـShell الأصلي شُغلت الاختبارات الـ16 مع `AUTH_LIVE_TEST=1` ونجحت جميعها.
في تحديث Cairo شُغلت فحوص الواجهة مع `AUTH_LIVE_TEST=0`، وتحقق الاختبار من أن FontFace
الخاص بـCairo محمّل فعليًا وأن جميع طلبات الخطوط محلية، مع منع الموارد الخارجية.
لا تُفعّل الفحص الحقيقي إلا بعد حاجز MySQL الاختبارية وتشغيل Laravel
بـ`--env=testing` كما في [توثيق الدخول](login-page.md). استخدم الفحص مستخدم `demo` الموجود
أصلًا في قاعدة الاختبار، ونجح الدخول ثم عرض الـShell وجلب المستخدم والخروج ورفض التوكن الملغى.
لا migrations أو seeders أو إنشاء مستخدمين أو قواعد بيانات في هذه المرحلة.

تشمل الفحوص المقاسات 320 و390 و768 و1024 و1440 و1920px، ومحاذاة الزاوية والفوتر، وعدم
التغطية أو overflow أفقي غير مقصود، وطي القائمة، ودرج الهاتف وTab/Escape والخلفية وإعادة
التركيز، وإغلاقه عند تغيير المقاس، ومحتوى اختبار طويل وعريض، والحساب وفشل الخروج.
استُخدمت استجابات ثابتة داخل اختبارات المتصفح المعزولة لفحوص الشكل وحالات الخطأ فقط؛
لا Fake API أو بيانات مستخدم وهمية ضمن التطبيق. الصور النهائية مأخوذة بحساب MySQL الاختباري
الموجود، ومحفوظة محليًا تحت `test-results/frame-*.png` مع `login-after-shell.png`.
رُوجعت الصور عند 1440×900 و1024×768 و390×844، بما فيها درج الهاتف. يتحقق اختبار
الساعة بمتصفح مضبوط على `America/Los_Angeles` ويقدم الوقت 60 ثانية عبر منتصف الليل
بتوقيت دمشق؛ يتغير التاريخ والوقت معًا دون hydration errors. تشمل الفحوص أيضًا
توسيع القائمة عند 768px، غياب حدود الإطار، الشعارين الأبيضين، وHover وreduced motion.

تأكدت المقارنة مع Git من عدم تغيير backend أو FastAPI أو API client أو منطق صفحة Login
أو أصول الهوية السابقة. تحديث Cairo يغيّر الخط العام في `globals.css` فقط ويضيف ملفه
وترخيصه المحليين؛ بقية تنسيقات Login والـShell محفوظة. قاعدة الإنتاج لم تُلمس.
الدمج والنشر خطوتان منفصلتان عن تنفيذ الواجهة والتحقق المحلي.
