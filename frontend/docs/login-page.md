# صفحة تسجيل الدخول

الصفحة ضمن Next.js الحالي على `/login`، مقتبسة من مستودع
`Hkgr/al-rowad-university-system`، فرع `develop` عند commit
`6f9b2f2582a8dce42b86b3d9637a082826e9703d`.
قُرئت ملفات LoginPage وLoginCard وAnimatedBackground وFloatingIcons، وملفات
`src/styles/global.css` و`cairo.css` والاعتماديات. نسخة المرجع للقراءة فقط؛ لم تُعدّل.

## التكوين والهوية

- بطاقة زجاجية بعرض 440px وزوايا 26px، padding ‏36/36/28px، حقول بزوايا 13px وفواصل 14px.
- بقي ترتيب العناصر والخلفية والبقع الخمس وشبكة النقاط والزوايا، وتوزيع الأيقونات العشرين وأحجامها وشفافيتها وإيقاع حركتها.
- استُبدلت أيقونات التعليم بأيقونات طبية من عائلة Font Awesome نفسها عبر `react-icons/fa`. استُخدمت Framer Motion للميلان وParallax وحركة الأيقونات.
- ألوان المشفى ومتغيراتها موحدة في `globals.css`؛ التفاصيل محصورة في CSS Module. لم يُستورد `brand-components.css`.
- ملفات SVG والخطوط وfavicon من الحزمة المرفقة كما هي. يتحرك إطار الدرع وحده. `MBZ Sans` بديل واجهة مبني على Noto، وليس ادعاءً بمعرفة خط الشعار الأصلي؛ ترخيص OFL موجود في `public/brand/fonts`.
- احتُفظ بألوان العلم السوري الأصلية. زاد ارتفاع البطاقة قليلًا لاستيعاب شعار الاسم العربي بنسبة أبعاده الأصلية؛ لم يُقص أو يُضغط الشعار ولم يُكرر الاسم نصيًا.
- انعكس موضع أيقونات الحقول وزر إظهار كلمة المرور ليتوافق مع RTL. تسميات الحقول متاحة لقارئ الشاشة، وزر الإظهار متاح بلوحة المفاتيح. تقليل الحركة يوقف الزخارف، وأجهزة اللمس لا تستخدم الميلان أو Parallax. المحتوى قابل للتمرير على الشاشات القصيرة.
- أُزيل «تذكرني» و«نسيت كلمة المرور» لأن المشروع لا يدعمهما. لا حسابات جديدة أو استعادة أو تغيير كلمة مرور في هذا العمل.

## المصادقة والتنقل

لم يكن في الواجهة عميل API أو تخزين جلسة أو لوحة داخلية. أضيف عميل صغير في
`src/features/auth/api.ts` يتصل بعقد Laravel الحالي:

```json
{"username":"user-name","password":"user-password","device_name":"hospital-web"}
```

يرسل `POST /api/login` ويقرأ `data.token` و`data.token_type` و`data.user` و`data.access`.
يطبّع اسم المستخدم بـtrim فقط. لا يستخدم البريد الإلكتروني أو عقد الجامعة.
الطلبات المحمية تستخدم `Authorization: Bearer ...` و`Accept: application/json`.
الاستجابات 401/403/422/429 وفشل الاتصال لها رسائل عربية؛ تفاصيل الخطأ الداخلية لا تُعرض.

التوكن محفوظ في `sessionStorage` الخاص بالتبويب، مع ذاكرة مؤقتة فقط إن منع المتصفح التخزين.
لا تستخدم الواجهة localStorage أو جلسات Laravel أو cookies للمصادقة. تخزين التوكن في المتصفح
يعني أنه متاح لجافاسكربت؛ ينبغي الحفاظ على منع XSS عند بناء الوحدات التالية. إغلاق التبويب
ليس طلب إلغاء توكن على الخادم؛ زر الخروج يستدعي Laravel ويلغي التوكن الحالي فقط، ثم يمحو
النسخة المحلية. فشل الخروج بسبب الشبكة يحتفظ بالتوكن لإعادة المحاولة.

بعد النجاح يتحول المستخدم إلى `/`، شاشة صغيرة تجلب الهوية مجددًا من `GET /api/user`
وتعرض اسم المستخدم والمنشآت المتاحة وزر الخروج. هذه ليست لوحة وحدات طبية جديدة.
`must_change_password` يعرض تنبيهًا دون اختلاق واجهة تغيير كلمة المرور.
لا تُستخدم الأدوار المخزنة محليًا لمنح الوصول؛ Laravel هو حد المصادقة والصلاحيات الفعلي.
إذا رفض الخادم التوكن بـ401 أو `ACCOUNT_INACTIVE` يُحذف محليًا.

## التشغيل المحلي الآمن

انسخ `.env.example` إلى `.env.local` داخل frontend واضبط `LARAVEL_API_URL` على نسخة Laravel
المحلية/الاختبارية المصرح بها. القيمة الإرشادية `http://127.0.0.1:8000/api`.
يمرّر Next.js المسارات الثلاثة فقط عبر `/hospital-api/login|user|logout` إلى Laravel؛
لا توجد مصادقة بديلة في Next.js. أعد التشغيل والبناء بعد تغيير العنوان.

```bash
npm ci
npm run dev
```

افتح `http://127.0.0.1:3000/login`. لا توجّه فحوص التطوير إلى الإنتاج.
إعداد `output: standalone` السابق محفوظ؛ عند تشغيل ناتج البناء مباشرة تُنسخ `public`
و`.next/static` إلى المسارات المقابلة داخل `.next/standalone` ويُشغّل `server.js`.

## التحقق

```bash
npm run build
npm run lint
npx playwright install chromium
npm run test:ui
git diff --check
```

اختبارات الواجهة تتطلب خادم Next.js محليًا قيد التشغيل؛ `TEST_BASE_URL` افتراضيًا
`http://127.0.0.1:3000`، ويُرفض أي مضيف بعيد. يمكن ضبط `PLAYWRIGHT_CHANNEL=msedge`
لاستخدام Edge المثبت على Windows. تُحجب الاتصالات الخارجية في المتصفح.
اختبارات أخطاء النموذج والتحميل تُحاكي استجابات API ولا تحتاج قاعدة بيانات.
الصور الناتجة تحت `test-results/` (مستثناة من Git).

الاختبار الحقيقي اختياري، ويتطلب أولًا حاجز Laravel الناجح:

```bash
php artisan test-db:check --connect --env=testing
php artisan serve --env=testing --host=127.0.0.1 --port=8000
```

ثم شغّل اختبارات الواجهة مع `AUTH_LIVE_TEST=1`. يستخدم هذا الاختبار مستخدم `demo`
الموجود أصلًا من seeder الخاص بـlocal/testing. لا ينشئ حسابات أو قاعدة بيانات ولا يشغل
migrations/seeders. إذا لم تكن قاعدة MySQL اختبارية معزولة متاحة، لا تفعّل هذا الاختبار.
المرجع الجامعي يُعرض في حاضنة محلية منفصلة للمقارنة البصرية فقط، مع حجب عنوان API الخاص به.

نتائج التنفيذ في 2026-09-10: نجح بناء Next.js وTypeScript وESLint. نجحت المصادقة الحقيقية
على MySQL `hospital_testing`، المضيف `127.0.0.1:13306`، وبيئة Laravel `testing`، بما يشمل
الدخول ثم جلب المستخدم ثم الخروج ورفض التوكن المحذوف. فُحصت 1440×900 و390×844 و320×480
و844×390، والخطوط والشعارات محلية بلا 404. المتصفح المدمج تعطل بخطأ بيئة الأداة؛ استُخدم
Edge محلي عبر Playwright للفحص والصور. لم يتغير backend أو FastAPI أو مخطط قاعدة البيانات،
ولم تُلمس قاعدة الإنتاج، ولم يحدث نشر أو دمج.
