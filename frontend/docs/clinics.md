# واجهة إدارة العيادات

`/clinics` و`/clinics/[id]` داخل AuthenticatedLayout الحالي، بخط Cairo المحلي وإطار AppShell نفسه. فُصل «الأطباء» (قريبًا) عن «العيادات»؛ يظهر رابط العيادات لمن لديه clinics.view في منشأة واحدة على الأقل. صلاحية الواجهة لا تحل محل تحقق Laravel في كل عملية.

القائمة تعرض رقمًا متتابعًا عبر الصفحات وكودًا يفتح التفاصيل، واسمًا وحالة وتوصيفًا مختصرًا وأسماء أطباء وعددين وإجراءات حسب الصلاحيات. الأطباء والأعداد تُحمّل من الخادم. البحث والفلاتر والترتيب والترقيم تحفظ في query string، والعودة من التفاصيل تبقيها. اختيار منشأة واحدة تلقائي، وأكثر من منشأة عبر اختيار مسموح.

البحث مؤخر 300ms، والطلبات السابقة تُلغى. كل نتيجة مرتبطة بمفتاح طلبها؛ لا يظهر سياق سابق أثناء بدء الطلب التالي. تغير المستخدم يعيد تركيب شجرة المصادقة الموجودة. التصدير يرسل الفلاتر والأعمدة المرئية إلى Laravel ليولد جميع النتائج، ولا يصنع تقريرًا من صفوف الصفحة الحالية.

النوافذ native dialog مع حصر التركيز وEscape وإعادته إلى الزر السابق، ومنع الإغلاق والإرسال المكرر أثناء الحفظ. أخطاء التحقق تظهر بجوار الحقول، والمدخلات تبقى بعد الفشل. اختيار الطبيب يرسل إضافات وإزالات صريحة؛ الخيارات غير المحملة أو المخفية لا تُسقط ارتباطاتها.

على الهاتف التمرير الأفقي محصور في الجدول، والنوافذ قابلة للتمرير على الشاشات القصيرة. تفاصيل العيادة والتصدير لا تكشفان بيانات المرضى. زر التعطيل منفصل عن الحذف ولا يُستدعى تلقائيًا عند رفضه.

عقود API، migration، سياسة الفترات والأعداد، الصلاحيات ومتطلبات التشغيل في [توثيق Laravel](../../backend/docs/clinics-api.md).

## إعادة الاختبارات

شغّل build وخادم Next محليًا، ثم اضبط TEST_BASE_URL إلى ذلك الخادم. اختبارات المتصفح ترفض المضيفين الخارجيين وتستعمل استجابات API اختبارية؛ تحتاج Chromium أو `PLAYWRIGHT_CHANNEL=msedge` على Windows.

```bash
npx tsc --noEmit
npm run lint
npm run build
npm run test:clinics
npm run test:shell
npm run test:dashboards
npm run test:ui
```

`CLINIC_CAPTURE=1` يعيد توليد الصور من اختبارات العيادات. اختبارات الواجهة تتحقق من التنقل، الصلاحيات الظاهرة، الرفض الفعلي للصفحة المباشرة عبر API، الأخطاء والمدخلات، فروق ارتباطات الأطباء، الحذف والتعطيل، التنزيل، استجابات متأخرة، لوحة المفاتيح والقياسات المحمولة. اختبار الدخول الحي الاختياري القديم يبقى مشروطًا بإعداداته الموثقة في auth-ui؛ نجاح اختبارات الاستجابات المحاكاة لا يُقدَّم على أنه اختبار شبكة حي.

صور الواجهة ملتقطة عند 390 و1440px، وتشمل القائمة والإضافة والأطباء والتفاصيل. اختبارات AppShell تشمل أيضًا قياسات 320 و768 و1024 و1920px. لم تتغير إعدادات الإنتاج أو FastAPI ولم يُنفّذ نشر.

فشل التشغيل الكامل الأول عند حد PHP المحلي 128MB أثناء تصدير Excel. النتيجة النهائية أعلاه بعد ضبط ذاكرة PHPUnit فقط إلى 256MB وتحرير مراجع قارئات ومولدات التقارير؛ لا تغيير على إعدادات ذاكرة الإنتاج.
