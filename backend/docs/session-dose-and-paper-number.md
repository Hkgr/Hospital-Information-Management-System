# اسم جرعة الجلسة واسم الممرض والرقم الورقي

هذه الإضافة تخص نافذة `session-dose` والقسم الأول من بطاقة المريض فقط. لا تغيّر الفواتير والتمويل أو صلاحيات إنشاء الأدلة أو حقول الإعطاء الفعلي والصرف.

## التسجيل والقراءة

- «اسم الجرعة» اختيار من الأدوية الفعالة غير المؤرشفة في التصنيف الموجود ذي الكود `AUTO-MCG-002` (نوعي). يبحث الخادم بالكود، دون تثبيت معرف التصنيف أو إنشاء تصنيف بديل. يلزم أيضًا أن يكون التصنيف فعالًا.
- تعرض `GET /api/dossiers/session-dose-medications?facility_id=…` الخيارات بعد فحص سياق المشفى وصلاحية العلاج. يرسل الحفظ `medication_id` ويعيد الخادم التحقق تحت القفل. لا تُقبل كتابة `dose_name` مباشرة؛ يحفظ الخادم اسم الدواء وقت اختياره كلقطة تاريخية.
- «اسم الممرض» نص مطلوب غير فارغ بعد إزالة الفراغات الطرفية، بحد أقصى 200 محرف. لا يحتاج حساب عامل أو ارتباط عيادة. لا يُنشأ عامل تلقائيًا.
- يبقى `nurse_id` القديم ومفتاحه الخارجي محفوظين. تعرض القراءة والتقارير `nurse_name` الجديد، أو اسم العامل المرتبط عند غياب النص. تستخدم القراءة ربطًا يساريًا كي تظهر السجلات الجديدة دون `nurse_id`.
- تعديل حقل آخر في جرعة قديمة لا يخمّن دواءً ولا يغيّر اسمها أو ارتباط الممرض. ترك `medication_id` و`nurse_name` دون إرسال يحفظ القيم التاريخية. تغيير الدواء صراحة يحتاج خيارًا مؤهلًا جديدًا ويحدّث لقطة الاسم؛ إعادة تسمية الدواء في الدليل وحدها لا تغيّر الجرعة المحفوظة.
- تعرض النافذة التحميل والفشل مع إعادة المحاولة وغياب الخيارات. لا تتيح إنشاء دواء لمدخل البيانات. تظل المعاملة والنسخ وUUID والتدقيق وفحص حالة الجلسة والمنشأة كما هي.
- «الرقم الورقي للإضبارة» يستخدم `patients.paper_file_number`: نص اختياري حتى 60 محرفًا، مثل `00042-A`، دون توليد أو تفرد جديد. يحفظ عند إنشاء الشخص وبطاقته ويظهر في القسم الأول بعد إعادة الفتح. حذف الحقل من طلب تعديل كامل يحفظ قيمته السابقة.
- يمكن لمن يملك صلاحية تعديل القسم الأول إرسال الرقم الورقي وحده مع نسختي البطاقة والمريض ومعرف الطلب. لا يتيح هذا المسار تغيير الاسم أو الميلاد أو تاريخ فتح الملف أو أي حقل هوية آخر، ولا يمنح تفويضًا عالميًا جديدًا. تبقى بقية الهوية ضمن ضوابطها الحالية.
