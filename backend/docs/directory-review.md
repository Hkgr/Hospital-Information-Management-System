## استعادة التعارض

تعتمد استعادة الطرفين على المعرّف الثابت، وتعرض الكود والاسم الحاليين مع تنبيه عند اختلافهما عن المسودة. لا يُستخدم الكود القديم للبحث عن وجود السجل. تُقرأ الارتباطات الحالية كلها، ثم الخيارات المتأثرة، ثم نسخة الطبيب/العيادة مرة أخرى؛ اختلاف `lock_version` يتطلب جلبًا جديدًا مع بقاء المسودة. اعتماد الاختيارات يعيد المستخدم إلى النموذج، والحفظ إجراء مستقل وصريح.

المساران الحاليان يدعمان طلب دفعة مكتملة:

```http
GET /api/doctors/options/clinics?facility_id=1&doctor_id=7&ids[]=12&ids[]=18
GET /api/clinics/options/doctors?facility_id=1&clinic_id=12&ids[]=7&ids[]=9
Authorization: Bearer <token>
Accept: application/json
```

`ids[]` اختياري: 1–100 معرّف صحيح موجب آمن في JavaScript، مع تفريد المكرر. لا يجتمع مع `search/page/per_page`. بدونه تبقى الخيارات قابلة للبحث والترقيم. استجابة الدفعة تعيد `data` و`meta` الحاليين و`unavailable: [{id, reason}]`؛ لا تُسقط النتائج بعد أول20 عنصرًا. `INACTIVE` لسجل/نوع معطل ضمن النطاق، و`UNAVAILABLE` يجمع المحذوف وغير المؤهل وخارج النطاق دون تمييز أو كشف هوية أو ارتباطات أجنبية. الخيارات العادية تعيد `unavailable: []`.

العيادات محصورة بالمنشأة المصرح بها؛ الأطباء يبقون ضمن دليل staff الطبي العالمي الحالي، وحالة ارتباطهم محصورة بالمنشأة والعيادة المختارتين. لا يمنح طلب المعرّف صلاحية إضافية. توثق OpenAPI المعامل المتكرر والحدود وحقل عدم الإتاحة.

تُفرّد الواجهة حتى400 معرّف، وتطلب بحد أقصى أربع دفعات100 لدعم200 إضافة و200 إزالة معًا. عدد SELECT في اختبار دفعة100 يساوي دفعة1. الإغلاق وتبديل المنشأة أو شجرة الجلسة يلغيان الطلبات؛ فشل إحدى الدفعات يلغي بقية الطلبات ويمنع مراجعة ناقصة. لا يُعاد إرسال ارتباط غير متاح، ولا تُستبدل المجموعة أو تُحذف الروابط المخفية. فشل الجلب والتعارض الثاني يبقيان المسودة قابلة للمحاولة.

## PDF وXLSX

يفصل `DirectoryReport` إخراج PDF عن `DirectorySpreadsheet`، ويتشاركان `ReportLayout` لتوزيع العرض حسب طبيعة العمود وقياس النص بخط Cairo المحلي. بقي اختيار الصفوف والفلاتر والأعمدة والتوقيت والمنفّذ والرقم والحدود في خدمات التقارير الحالية.

- PDF: شعار أصلي132px، عنوان21pt، بيانات جدول10.5pt، رؤوس10pt، بيانات ثانوية9–9.5pt. ترويسة أولى منظمة وترويسة استمرار مختصرة، تذييل مرقّم وهوامش آمنة. A4 أفقي لأكثر من أربعة أعمدة وعمودي للتفاصيل والقوائم المختصرة. Cairo Regular/Bold ثابتان مضمنان، مع تشكيل العربية ومنع التصغير الشامل والموارد الخارجية.
- قياس التفاف النص هو معيار الملحق، وليس عدد أحرف ثابتًا. التوصيف المعتدل يبقى في الجدول؛ النص الذي يتجاوز12 سطرًا مقدّرًا بعرض عموده ينتقل كاملًا إلى ملحق باسم السجل وكوده ومرجع ظاهر. الملحق يتدفق بعد الجدول دون فرض صفحة جديدة. ملاحظة احتساب المرضى مرتبطة بالجدول. التفاصيل تعرض شبكة حقول وأعداد وقسم «توصيف العيادة» أو «التوصيف المهني» ثم الارتباطات.
- XLSX: Cairo10.5pt افتراضيًا لكل الأوراق، RTL، عنوان18pt، أكواد ونصوص من النوع النصي الصريح، أعداد رقمية، فلاتر وتجميدA9، دون دمج جسم البيانات. ارتفاع الصف يتبع التفاف النص، ولا تُقصّر قيمة الخلية العادية. يُقاس عرض العمود بوحدات خط Normal الفعلية وفق [تعريف Microsoft لوحدات الأعمدة](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.column?view=openxml-3.0.1)، بدل تحويل يفترض خطًا مختلفًا.
- عند تجاوز16 سطرًا مقدّرًا في Excel، تبقى القيمة كاملة في الخلية ما دامت ضمن32767 وحدةUTF-16. تنسيق عرض نصي يظهر مقتطفًا معلّمًا، وتعليق ورابط يوضحان وجود النص الكامل في شريط الصيغة وورقة «النصوص للطباعة». يمكن إزالة تنسيق العرض لرؤية القيمة الخام. هذه معالجة لحد ارتفاع صف Excel، وليست استبدالًا للقيمة أو قصًا صامتًا.
- ورقة الطباعة تربط النص بمعرّف السجل وكوده واسمه والحقل ورقم الجزء. تقسيمها حسب عرض الطباعة وميزانية14 سطرًا، مع حفظ المسافات والترتيب، لا أجزاء200 حرف. إذا تجاوز النص حد الخلية الفعلي، يحمل الجدول مرجعًا صريحًا وتُحفظ الأجزاء الكاملة في ورقة «بيانات النصوص»؛ تُخفى ورقة التخزين عن الطباعة الآلية ويمكن إظهارها من Excel. النسخة المقروءة كاملة في ورقة الطباعة.
- الطباعة: Print Area محدد، رؤوس متكررة، Fit to Width=1 وHeight=0. في معاينة Microsoft Excel16 مع Cairo مثبت بلغ خط جسم التقرير نحو10.56pt، والعنوان18pt. قارنت ارتفاعات الصفوف مع AutoFit في Excel وضبطتها بهامش4pt تقريبًا؛ لا تغيير في القيمة الكاملة أو حجم الخط لتقليل عدد الصفحات.

**PDF يضمّن Cairo؛ XLSX يحدد اسمه ولا يضمّنه. يجب تثبيت Cairo على جهاز فتح XLSX.** قد تختلف فواصل الطباعة باختلاف البرنامج والطابعة والخط المثبت. يبقى قياس التصدير قرب حد1000 سجل/5000 ارتباط على staging عملًا لاحقًا.

## العينات والمعاينة الفعلية

حُفظت18 وثيقة تقرير اصطناعية قبل تعديل المولّد في [documents.json](samples/comparison/documents.json). أُعيد تمرير الوثائق نفسها للمولّد الجديد؛ الصفوف والفلاتر والأعمدة وأرقام التقارير والمُصدر والأوقات متطابقة قبل/بعد لكل ملف. لكل وحدة قائمة40 سجلًا بكل الأعمدة، قائمة40 بعمودين، قائمة3 بأربعة أعمدة وتوصيف معتدل، قائمة3 بعمود واحد، وتفاصيل بتوصيف طويل. تشمل أسماء طويلة وأكوادًا بأصفار وأعداد مرضى صفرية.

| النوع | الأطباء قبل ← بعد | العيادات قبل ← بعد |
| --- | --- | --- |
| PDF القائمة الكاملة | 9 ← 7 صفحات | 7 ← 5 صفحات |
| PDF المختصر / القصير / العمود الواحد / التفاصيل | 2/2/1/2 ← 2/1/1/2 | 2/2/1/2 ← 2/1/1/2 |
| طباعة Excel للقائمة الكاملة | 12 ← 12 صفحة | 16 ← 9 صفحات |
| طباعة Excel المختصر / القصير / العمود الواحد | 2/2/1 ← 2/1/1 | 2/2/1 ← 2/1/1 |

راجعت صور **كل121 صفحة**:68 قبل و53 بعد (24 PDF من Laravel و29 صفحة طباعة Excel بعد الإصلاح). فُتحت ملفات XLSX الثمانية لكل مرحلة في **Microsoft Excel16** مع Cairo محلي، وفُحصت جميع الأوراق، وأُخرجت معاينات الطباعة منه مباشرة؛ لم يُستخدم LibreOffice. صور الورقة `*-sheet-*.png` من Excel، وتعرض بداية الورقة حتى12 صفًا؛ صور الطباعة تشمل كل الصفحات. لا تمثل هذه العينات اختبار HTTP حيًا.

عالجت دورات المعاينة الترويسة الكبيرة، ونقل الأوصاف المعتدلة إلى ملحق بلا حاجة، وضعف توزيع الأعمدة، وتصغير Excel إلى9.36pt في محاولة أولى، وارتفاعات الصفوف المبالغ بها، وصفحة PDF تحتوي ملاحظة فقط. بقي النص الكامل والتسلسل ومرجع الملحق؛ لا يُفرض عدد صفحات على حساب القراءة.

تشمل الاختبارات دفعة100 كاملة دون نمو SELECT لكل عنصر، و400 تغيير بأربع طلبات خيارات فقط، والهوية الحالية للطرفين، وعزل المنشأة، والفشل والمحاولة والتعارض المتكرر، والإلغاء عند الإغلاق/المنشأة/الجلسة، والحفظ الصريح، والنصوص والأنواع وUnicode وحد الخلية وتضمين الخط. لم يُعد تشغيل مسار HTTP الحي أو كامل اختبارات الوحدات غير المتأثرة أو staging في هذه المراجعة؛ نتائجها القديمة موضحة كتاريخية في دليل الواجهة. توقف اتصال قاعدة الاختبار بعد انقطاع الجلسة؛ أعيد تشغيل **مجلد الاختبار الموجود نفسه** دون إنشاء قاعدة أو تهيئة بيانات، ثم أعيد الحاجز والاختبارات.

لإعادة المقارنة دون تغيير مصدرها، من backend:

```bash
php tests/Support/replay-directory-samples.php
```

هذا المساعد يتطلب APP_ENV=testing ويقرأ documents.json دون أي اتصال قاعدة بيانات. إنشاء بيانات اصطناعية جديدة منفصل عبر `generate-directory-samples.php`؛ يطبق حاجز MySQL ويستخدم rollback. خيار `--capture-baseline` يرفض استبدال ملف المقارنة الموجود، ولا يعيد إنتاج المولّد القديم تلقائيًا.

للمعاينة من جذر المستودع على Windows مع Microsoft Excel وCairo وMicrosoft Print to PDF:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File backend/tests/Support/review-excel-reports.ps1 -Stage after -CaptureSheets -MeasureRows
```

يفتح جلسة Excel خاصة، ويعطل macros/events/links، ويغلق المصنفات دون حفظ تعديلات المعاينة. خيار الصور يظهر Excel مؤقتًا. لا يغيّر الطابعة الافتراضية للنظام. من frontend، بأدوات المعاينة الاختيارية الموثقة في [doctors.md](../../frontend/docs/doctors.md):

```bash
node tests/render-directory-reports.mjs after
node tests/report-comparison.mjs
```

يرسم المساعد كل الصفحات ويفحص الخطوط وأحجامها الفعلية؛ تُنشأ لوحات اتصال لجميع الصفحات في `.superdesign/report-review` للمراجعة، وصور المقارنة في docs. لا تتغير اعتمادات التشغيل: Composer الحالي وTTF المحلي ومجلد cache القابل للكتابة كما في [deployment.md](deployment.md).
