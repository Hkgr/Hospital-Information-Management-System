# عينات تقارير اصطناعية

هذه الملفات للمراجعة فقط، وليست بيانات مرضى أو أطباء حقيقيين. `generate-directory-samples.php` ينشئ40 طبيبًا و40 عيادة وارتباطات وتوصيفًا عربيًا طويلًا، ثم يعيد كل صفوفه وsequences بـrollback داخل MySQL اختبارية اجتازت الحاجز. أرقام التقارير هنا تجريبية ولا يُستدل منها على تسلسل الإنتاج.

- `doctor-list` و`clinic-list`: جميع الأعمدة ونتائج متعددة الصفحات، مع ملحق النص الكامل في PDF وورقة إضافية في XLSX.
- `doctor-compact` و`clinic-compact`: الكود والاسم فقط، لاختبار قلة الأعمدة وحفظ الأصفار.
- `doctor-detail.pdf` و`clinic-detail.pdf`: تفاصيل رأسية بتوصيف طويل كامل وارتباطات حالية.
- `live-doctor.pdf/.xlsx`: تنزيل فعلي من Laravel عبر HTTP بعد تسجيل الدخول وإنشاء طبيب وربطه بعيادتين في قاعدة الاختبار.
- `*-excel-preview.pdf`: معاينة طباعة خرجت من Microsoft Excel16 بعد فتح ملف XLSX الأصلي، وليست نسخة من قالب mPDF.

تضمّن ملفات PDF الصادرة من Laravel Cairo Regular وBold. يحدد XLSX اسم Cairo دون تضمينه؛ ثبته محليًا لضمان العرض نفسه. الخط مثبت على جهاز المراجعة. صور كل الصفحات في `frontend/docs/screenshots/{doctors,clinics}/pdf`، وصور واجهات الوحدتين عند390 و768 و1440px في المجلدين المقابلين.

أدوات live تكتب بيانات دخول اصطناعية وتوكنًا في `backend/storage/framework/testing` المتجاهل فقط؛ ليست ضمن هذه العينات أو Git. كل أدوات إعداد البيانات تطبق TestDatabaseSafety قبل الاتصال. لا تشغّلها على تطوير أو إنتاج.
