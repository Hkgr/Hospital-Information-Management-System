# سجل الحركة

`GET /api/audit` يعرض جدول `audit_logs` للمنشأة المختارة. `GET /api/audit/{id}` يعرض حركة واحدة. يتطلب حسابًا فعالًا وتوكن Bearer بقدرة `api` وعضوية في `facility_id`. لا صلاحية جديدة ولا منح تلقائي.

التصنيفات: بطاقة المريض، العلاج والأدوية، الدليل، المخزون، بنك الدم، الحسابات، خطأ تقني، أخرى. كل صف يحمل وقت المنشأة واسم المستخدم.

تسجيل الدخول والخروج يُحفظان كـ `auth_session` عندما يملك المستخدم منشأة. الاستثناءات غير المتوقعة تُحفظ كـ `system_error` برسالة مختصرة بلا أثر تقني أو أسرار. طلبات القراءة لا تكتب في السجل.
